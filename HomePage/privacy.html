OpenTrace 隐私政策

生效日期：2026 年 7 月 26 日

OpenTrace 是开源网络诊断工具。本政策说明 OpenTrace 在 Windows 应用和本网站中如何处理信息。

1. 我们不收集的内容

OpenTrace 不要求创建账户，不运营自己的用户资料、广告、行为分析或遥测服务，也不会出售个人信息或将个人信息用于跨情境行为广告。

2. 在设备本地处理和保存的信息

为提供功能，应用会在你的设备上保存你选择的设置，例如界面语言、路由追踪历史、所选协议和 DNS 解析器、外部 NextTrace 或本地 MMDB 文件路径、地图与隐私遮罩设置，以及你自行填写的 API 令牌或自定义服务地址。这些信息由应用本地保存；除非你自行导出、复制或配置第三方服务，OpenTrace 不会把它们上传到由 OpenTrace 项目运营的服务器。

3. 网络诊断和第三方服务

当你开始路由追踪、MTR、DNS 解析、IP 地理位置查询或地图显示时，应用会代表你与相关网络服务通信。这可能包括：

  • 向你输入或选择的目标主机、IP 地址及中间网络设备发送诊断探测；
  • 向你选择或配置的 DNS 解析器发送域名查询；
  • 在你启用 IP 地理位置功能时，将跳点 IP 地址发送给你选择或配置的 IP 地理位置服务；如你提供 API 令牌，令牌也会被用于该服务；
  • 在你启用地图功能时，向所选地图服务（例如 Baidu Maps、Google Maps 或 OpenStreetMap 及其内容传输服务）请求地图资源，并向地图视图提供跳点的地理位置数据；
  • 在你启用启动时检查更新时，向 GitHub 的发布接口查询最新版本信息。

这些第三方服务会按照其各自的隐私政策处理请求信息，其中通常可能包括你的 IP 地址、请求时间、设备/浏览器信息、查询内容以及服务所需的认证令牌。你可以在应用设置中禁用 IP 地理位置、地图、更新检查，或改用本地 IP 数据库和自定义 DNS/服务。

4. 信息用途

应用仅将上述信息用于执行你请求的网络诊断、显示结果、保存你的本地偏好设置，以及（如启用）检查可用更新。OpenTrace 不使用这些信息建立用户画像。

5. 共享、保留与安全

OpenTrace 项目不运营用于接收诊断数据的中央服务器。应用本地设置会保留在你的设备上，直至你在应用中删除、重置应用数据或卸载应用。你自行导出的结果、复制到剪贴板的内容和发送给第三方服务的信息由你控制。请勿将敏感主机名、令牌或其他机密信息输入到不受信任的第三方服务。

6. 你的选择和权利

你可通过应用设置查看或修改本地偏好设置、关闭可选网络功能、选择本地 IP 数据库，或卸载应用以删除其本地数据。若你所在地区的法律赋予你访问、更正、删除或限制处理个人信息的权利，请通过下方联系方式提出请求；由于我们不运行 OpenTrace 用户数据服务器，我们通常无法访问你设备上的本地数据。

7. 儿童

OpenTrace 并非面向儿童设计，也不会故意收集儿童的个人信息。

8. 政策更新与联系我们

若功能或法律要求发生变化，我们可能更新本政策，并在本页更新生效日期。有关隐私问题，请在 OpenTrace GitHub Issues 联系我们。

OpenTrace Privacy Policy

Effective date: July 26, 2026

OpenTrace is an open-source network diagnostic tool. This policy explains how information is handled by the Windows application and this website.

1. Information we do not collect

OpenTrace does not require an account and does not operate its own user-profile, advertising, behavioral-analytics, or telemetry service. We do not sell personal information or use it for cross-context behavioral advertising.

2. Information processed and stored locally

To provide its features, the app stores selected preferences on your device, such as interface language, trace history, selected protocol and DNS resolver, paths to an external NextTrace executable or local MMDB file, map and privacy-masking settings, and any API tokens or custom service addresses you enter. This information is stored locally by the app. OpenTrace does not upload it to servers operated by the OpenTrace project unless you choose to export, copy, or configure a third-party service.

3. Network diagnostics and third-party services

When you start traceroute, MTR, DNS resolution, IP geolocation, or map display, the app communicates with relevant services on your behalf. This may include:

  • sending diagnostic probes to the destination host or IP address you enter and to intermediate network devices;
  • sending domain-name queries to the DNS resolver you select or configure;
  • sending hop IP addresses to the IP-geolocation service you select or configure when geolocation is enabled; if you provide an API token, that token is used with that service;
  • requesting map resources from the selected map service, such as Baidu Maps, Google Maps, or OpenStreetMap and its content-delivery services, and supplying hop geolocation data to the map view;
  • checking GitHub release information when the optional startup update check is enabled.

Those third parties process requests under their own privacy policies and may receive information such as your IP address, request time, device or browser information, query content, and any required authentication token. You can disable IP geolocation, maps, and update checking, or use a local IP database and custom DNS/services in the app settings.

4. How information is used

The app uses this information only to perform the network diagnostics you request, display results, preserve local preferences, and, if enabled, check for available updates. OpenTrace does not use it to create user profiles.

5. Sharing, retention, and security

The OpenTrace project does not operate a central server that receives diagnostic data. Local app settings remain on your device until you delete them in the app, reset app data, or uninstall the app. Results you export, content you copy to the clipboard, and information you send to third-party services are under your control. Do not enter sensitive host names, tokens, or other confidential information into untrusted third-party services.

6. Your choices and rights

You can review or change local preferences, disable optional network features, select a local IP database, or uninstall the app to remove its local data. If laws in your region grant rights to access, correct, delete, or restrict processing of personal information, contact us below. Because we do not run a server containing OpenTrace user data, we generally cannot access data stored on your device.

7. Children

OpenTrace is not designed for children and does not knowingly collect children’s personal information.

8. Changes and contact

We may update this policy when features or legal requirements change and will revise the effective date on this page. For privacy questions, contact us through OpenTrace GitHub Issues.
